# Engineering Brain

The engineering brain is structured in three layers:
- **L0 — Decisions**: Why something was built a certain way, tradeoffs made, alternatives rejected
- **L1 — Synthesis**: Patterns that emerged across sessions, recurring solutions
- **L2 — Architecture**: Structural knowledge about the project that changes rarely

## Brain tools — use proactively

- `brain_context`: Call at the start of any significant task to surface what the brain already knows.
- `search_brain`: Use before answering architectural or historical questions.
- `save_to_brain`: Call after making architectural choices, solving hard problems, or learning something worth remembering.
  - L0 for a specific decision made this session
  - L1 for a pattern that has appeared more than once
  - L2 for a structural fact that is unlikely to change

Never let important decisions disappear into chat history. If you make a significant call — capture it.
